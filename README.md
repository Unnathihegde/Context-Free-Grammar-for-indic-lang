# Context-Free Grammar for Indic–Dravidian Languages (Telugu Case Study)

This project investigates whether explicit hierarchical grammatical structure—induced from a small Universal Dependencies treebank—helps a language model rank grammatical sentences above ungrammatical ones in Telugu, particularly under low-resource data constraints.

> **Key Finding**: The learned PCFG did **not** outperform a simple POS-bigram baseline on word-order minimal-pair tests (PCFG accuracy **0.944** vs. POS-bigram baseline **0.967**, $p \le 0.002$ (smallest value resolvable with 1,000 bootstrap resamples)). In small, head-final Telugu sentences, canonical word order constraints are predominantly local patterns that low-order n-gram transitions capture effectively without hierarchical syntax. While the PCFG achieved higher accuracy on `case_before` (0.821 vs. 0.696 across 56 pairs), this advantage is not statistically significant ($p = 0.058$).

## Setup

```bash
# 1. Clone repository and navigate to folder
cd "Context free grammar for indic lang"

# 2. Set up virtual environment
python -m venv .venv

# On Windows PowerShell:
.venv\Scripts\Activate.ps1
# On Linux/macOS:
# source .venv/bin/activate

# 3. Install dependencies
pip install -r requirements.txt
```

## Commands & Reproduction

All metrics in this project are dynamically computed from scripts and saved to `results/`.

```bash
# Run the test suite (16 tests)
python -m pytest -q

# 1. Induce PCFG and report held-out parse coverage
python src/grammar_learn.py

# 2. Evaluate minimal pairs with PCFG (5-fold CV)
python src/pairs_eval.py

# 3. Run full word-order benchmark (PCFG vs. POS-Bigram with sentence bootstrapping)
# Writes: results/wordorder_results.csv
python scripts/run_wordorder.py

# 4. Extract candidate agreement pairs from treebank
# Writes: data/agreement/agreement_pairs_candidates.csv
python src/agreement.py

# 5. Run agreement evaluation (prints loud unvalidated/demo warnings)
# Writes: results/agreement_results.csv
python scripts/run_agreement.py

# 6. Run data-size learning curve across training sizes
# Writes: results/datasize_curve.csv and results/datasize_curve.png
python scripts/run_datasize_curve.py

# 7. Launch interactive Streamlit demo app
streamlit run app/streamlit_app.py
```

## Data & Licensing

- **Universal Dependencies Telugu-MTG**: The treebank `.conllu` files belong in `data/`. The treebank repository lists two licenses: **CC BY-SA 4.0** and **CC BY-NC-SA 3.0**. Users must confirm licensing terms with the upstream source before redistribution.
- **Language Model Corpus**: The raw training corpus must be placed by the user at `data/raw/telugu_corpus.txt` (one sentence per line). `data/raw/` is excluded from version control via `.gitignore`. Do not commit raw language corpora.
- **Background Literature**: Early planning referenced the historical grammar text *Bala Vyakaranam*. As physical scans were unreadable by OCR, the book is considered background reading only; no grammar rules in this repository are derived from or attributed to it.
